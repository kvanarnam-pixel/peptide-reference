# Seasonal Allergies

## The system

The failure is a Th2-leaning mucosal response plus a barrier that has been beaten up by the season — IgE / histamine / irritated lining. Antihistamines and allergen avoidance still do the acute job. This page is barrier and immune-tone conversation, not a replacement antihistamine.

Easy page to over-stack. Six names in the source notes do not mean six jobs.

## Category one — the lining (primary)

**BPC-157** — mucosal repair coordinator. Same lining job as the gut page, aimed at airway and sinus mucosa here. Oral vs injectable lives on the BPC card.

**GHK-Cu** — barrier / matrix remodeling. Materials-and-blueprints next to the foreman. Complementary on paper. Not an allergy trial.

## Category two — quiet the mucosa (primary when it is angry)

**KPV** — NF-κB-type quieting at the lining. Fits an inflamed, reactive mucosa. Does not block histamine receptors.

## Category three — immune tone (support, real job)

**Thymosin Alpha-1** already has a card. The job is immune modulation — Th1/Th2 balance language — which is a closer match to “seasonal Th2 tilt” than MOTS-c or TB-500. Still not a licensed allergy biologic. Support, not a substitute for an allergist.

## Named in the source notes — thinner jobs, not default on this page

**MOTS-c** was listed as metabolic / immune backdrop. Seasonal pollen is not a GLUT4 problem. Borrowed. Leave it off the public pairing unless the person already has a live metabolic map.

**TB-500** is the access crew. Useful when there is actual tissue damage to reach. Allergic mucosa is usually inflamed, not a wound-repair site. Leave it off the default list so this page does not become a second Wolverine stack.

**Nicotine** (patch) appears in the source notes as a cholinergic / immune odd-pathway. Same caution as the IBS page: not a default allergy tool, not dosed here.

## Markers people track

None required for a typical seasonal picture. Specific IgE belongs with an allergist if the story is not straightforward.

## Oral supports that actually map

- Quercetin — mast-cell neighborhood
- Vitamin D3, zinc, vitamin C
- Selenium
- Magnesium glycinate

## Evidence tier

**BPC-157 / GHK-Cu / KPV** — barrier + quieting. Mechanism, not an allergy RCT.  
**Thymosin Alpha-1** — immune-modulating job is coherent; seasonal-allergy outcome data are not.

No combined human trial. Do not drop an inhaler or an EpiPen plan because this list exists.

## What this does not cover

Anaphylaxis, asthma flares, or a first-time wheeze. Those exit this page.

## Related compounds

BPC-157, GHK-Cu, KPV, Thymosin Alpha-1. Doses live on those cards.
