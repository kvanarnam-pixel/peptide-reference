# Immunosenescence & Immune Support

## The system

The failure is an aging immune system that makes more noise and less precision — fewer naive T cells, sloppier NK function, more inflammatory chatter. Thymic peptides show up here for that reason.

This page is immune-modulating conversation. It is not an infection treatment and not a vaccine.

## Category one — the actual immune-modulating center

**Thymosin Alpha-1** already has a card. That is the rationale for this tile. T-cell / innate-precision language. Course-based on its own card. Not a daily forever immune drug.

## Category two — repair backdrop (thin)

**BPC-157** is generic repair / inflammatory coordination. It does not restore a thymus. Leave it off if the only question is “my shots do not take and I get every virus.”

## Named and left off the default list

**Nicotine** (patch) appears in the source notes as a cholinergic / immune odd-pathway. Same public-language rule as the gut and allergy pages: not a default immune tool, not dosed here.

## Markers people track

CBC, vitamin D, vaccination status. HIV / hepatitis screening when a clinician would already order them. This map does not invent an “immune panel” of peptide markers.

## Oral supports that actually map

- Vitamin D3
- Zinc
- Vitamin C
- NAC
- Omega-3

Cordyceps is in the source notes. Optional; not a required add.

## Evidence tier

**Thymosin Alpha-1** — the only compound on this page whose job is actually immune modulation.  
**BPC-157** — Tier 3 here.

No combined human “reverse immunosenescence” trial.

## What this does not cover

Active infection, fever workup, immunodeficiency diagnosis, or using a nicotine patch as an immune drug.

## Related compounds

Thymosin Alpha-1, BPC-157. Doses live on those cards.
