# Anxiety & Threat-Tone Support

## The system

The failure is a threat system that will not stand down — GABA / monoamine / HPA neighborhood, not a missing memory peptide. Sleep, caffeine, alcohol, thyroid, and apnea impersonate “anxiety” daily.

This page is threat-tone conversation. It is not an antidepressant, not anxiolytic prescribing, and not the cognitive-fog page.

## Category one — the only peptide whose job is this (primary)

**Selank** already has a card. Tuftsin analog. Anxiolytic / enkephalin-neighborhood conversation in the research literature. That is why it sits here instead of on Cognitive Support, where it was only a side note.

## Category two — sleep architecture if that is how threat stays on

**DSIP** — centered on the insomnia page. Import it here only when the anxiety story is “the night never lands, so the day starts already loud.”

## Category three — HPA backdrop (thin)

The chronic-stress page owns cortisol. Do not copy that stack. Phosphatidylserine and magnesium are the honest orals if night cortisol is part of the threat tone.

## Markers people track

Thyroid, B12, ferritin, morning cortisol if HPA is the question. A GAD score is not a peptide indication.

## Oral supports that actually map

- Magnesium glycinate
- L-theanine
- Glycine
- Phosphatidylserine if night cortisol is live

## Evidence tier

**Selank** — the rationale for this tile.  
**DSIP** — sleep import only.

No combined human “peptide antidepressant” trial. This page will not use that frame.

## What this does not cover

Suicidality, mania, panic with cardiac workup still open, or stopping a prescribed SSRI / benzodiazepine.
