# Systemic Multi-Organ Support

## The system

This is a bundle, not a diagnosis. “Everything is worn” is usually four jobs stacked: inflammatory tone, fibrosis / matrix, local repair, and mitochondrial strain — across more than one tissue.

This page is an index, not a seventh copy of the repair stack. If one organ is the actual problem, use that organ’s tile.

## How to use this page

Pick the organ failure that is actually loud:

- Metabolic / glucose → Insulin Resistance
- Liver enzymes → Hepatic Inflammation
- Nerves → Diabetic Neuropathy (or Small-Fiber Support)
- Gut lining → IBS & Gut
- Vessel pressure → Hypertension
- Heart rhythm history → Atrial Fibrillation overlay
- Immune aging → Immunosenescence

Then add one overlay from below. Do not run every name on this page at once. More compounds is not more biology.

## Category one — quiet the signal

**KPV** — systemic NF-κB-type quieting when hs-CRP or a cytokine story is the common thread.

## Category two — repair and matrix (do not stack all three by default)

**BPC-157** — local repair coordinator.  
**TB-500** — access / anti-fibrotic conversation.  
**GHK-Cu** — matrix remodeling / gene-expression language.

Foreman, access crew, materials. Complementary on paper. Running all three plus everything else is the over-stack this page exists to prevent.

## Category three — mitochondria in expensive tissue

**SS-31** — membrane protection.  
**ARA-290** — innate-repair-receptor / tissue-protection angle from the source map. Already centered on the neuropathy page. Import it here only when nerve or microvascular protection is part of the worn picture — not as a default multi-organ add.

## Markers people track

hs-CRP, GGT, ALT / AST, metabolic dashboard, eGFR, A1c — whichever organ is actually in the room. LDH / lactate only if energy failure is the question.

## Oral supports that actually map

Glycine, proline, lysine (collagen neighborhood), magnesium, omega-3, NAC, vitamin D3 / K2, TUDCA if the liver is part of the bundle.

## Evidence tier

This page is a map of overlapping jobs, not a trial arm. No combined human “multi-organ peptide protocol.”

## What this does not cover

Acute organ failure, cancer-surveillance questions around angiogenesis-related compounds, or using this list instead of the organ workup.

## Related compounds

KPV, BPC-157, TB-500, GHK-Cu, SS-31. ARA-290 only when that job is live. Doses live on those cards.
