# Tesamorelin Body Recomposition

## The system

Two different failures get sold as “fat loss.” Appetite drugs change intake and partitioning. The GH axis changes how visceral fat and lean tissue are handled through GHRH → GH → IGF-1. Tesamorelin is a GHRH analog with an FDA-labeled use for excess abdominal fat in HIV-associated lipodystrophy. Using that same visceral-fat biology as a general recomposition tool is off-label conversation, not the labeled indication.

This page maps that GH-axis job, plus one distinct fat-cell NAD job that showed up next to it in the source notes. It is not a second Retatrutide page.

## Category one — the GHRH / visceral-fat signal (primary)

**Tesamorelin** already has a card. Daily GHRH-receptor drive, short half-life, visceral-fat lipolysis language, IGF-1 rise. That is the center. Sleep apnea, untreated malignancy questions, and IGF-1 monitoring belong with a clinician — GH-axis agents are not casual.

**CJC-1295 (with DAC)** is also a GHRH analog. Same receptor family, longer duration. Stacking it with Tesamorelin is a second copy of category one, not a new job. Left off this page.

**Ipamorelin** is a different receptor (GHS-R1a, pulse *amplitude*). Complementary on paper to a GHRH analog. Not required to finish Tesamorelin’s visceral-fat job, and this page is not the bedtime GH-optimization stack. Lives on its own card. Not default here.

## Category two — fat-cell NAD drain (distinct job, source pairing)

**5-Amino-1MQ** already has a card. It is an NNMT inhibitor — a small molecule, not a peptide — aimed at the NAD leak inside white fat. That is not GHRH. Source papers paired it with Tesamorelin as clinic convention during aggressive fat-loss. Distinct mechanism. Not a combined human recomposition trial. Keep it on the public map because the job is actually different.

## Category three — intake / partitioning, only if both tools are already in play (different job)

**Retatrutide** does not copy Tesamorelin. GLP-1 / GIP / glucagon changes how much comes in and how fuel is routed. If someone is already on both, they are doing two jobs. If they are not, do not add Retatrutide to “complete” a Tesamorelin page. Different system failure.

## Markers people track

- Body composition, not scale alone
- Fasting insulin and glucose
- IGF-1 if a clinician is actually running a GH-axis agent
- Sleep-apnea screen — GH-axis work and apnea fight each other

## Oral supports that actually map

- Magnesium glycinate
- Glycine (evening in the source notes — sleep / GH-pulse neighborhood)
- Protein and training — the lean-mass half of “recomp” is not a peptide

## Evidence tier

**Tesamorelin** — human visceral-fat data exist in the labeled population. General recomposition is extrapolation.  
**5-Amino-1MQ** — NNMT mechanism; pairing with Tesamorelin is convention.  
**Retatrutide** — human metabolic data on its own card; not a Tesamorelin combination trial.

No combined human trial of Tesamorelin + 5-Amino-1MQ + Retatrutide.

## What this does not cover

The approved HIV-lipodystrophy indication as if it were a lifestyle protocol. Active malignancy questions around GH-axis agents. Untreated apnea. Stacking secretagogues because more GH-shaped names feel stronger.

## Related compounds

Tesamorelin, 5-Amino-1MQ. Retatrutide only if that job is already live. Doses and cycling live on those cards.
