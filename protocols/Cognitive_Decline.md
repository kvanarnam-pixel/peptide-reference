# Cognitive Support

## The system

“Brain fog” is a complaint, not a diagnosis. Sleep, thyroid, B12, apnea, depression, and glucose swings impersonate it daily. When those are not the whole story, the remaining conversation is hippocampal and cortical energy, plus a neurotrophic signal that is studied for attention and plasticity.

This page is support for that energy-and-signal picture. It is not a dementia protocol, not an Alzheimer’s stack, and not a substitute for a workup when decline is actually the word that belongs.

## Category one — the energy the neurons run on (primary)

Neurons are expensive. The same mitochondrial pair used on the insulin-resistance page maps here because fog that tracks meals, crashes, or poor recovery is often fuel handling, not a missing nootropic.

**MOTS-c** — AMPK / fuel-flexibility / mitochondrial programming. Not a focus drug.

**SS-31** — cardiolipin / electron-transport membrane in high-ATP tissue. Wiring, not a stimulant.

**NAD+** — redox carrier those pathways use. Biochemistry is real; “injectable NAD+ for brain fog” as a standalone human outcome is not. Cofactor, not a fourth energy drug.

## Category two — the neurotrophic note (primary when energy is not the whole complaint)

**Semax** already has a card in this app. It is an ACTH(4–10) analog used as an intranasal BDNF / NGF-type signal — attention, plasticity, recovery-from-demand language. That is a different job from MOTS-c. It does not fix apnea or a B12 of 180.

The source notes put Semax next to the energy pair on purpose: machinery first, then a growth-factor-style signal. Sequence is the point. Do not open this category because the word “cognitive” is on the tile.

## Category three — only if anxiety is part of the fog (support)

**Selank** is a tuftsin analog in the same intranasal neighborhood. GABA-A-modulating, anxiolytic-leaning, not sedating in the benzodiazepine sense. On this page only when the fog is loud because the alarm system will not stand down. If the picture is clean energy-and-focus with no anxiety story, leave it off.

## Named in the catalog — not on this page

**Dihexa** is in the library and its own card already says it is not an entry-point peptide: do not build synapses on a brain that is still inflamed, under-fueled, or glucose-dysregulated. That warning is the reason it stays off this public map.

**Cerebrolysin** and **Adamax** are also catalog compounds. This page does not pull the whole cognitive shelf onto one stall. If those cards are relevant, they live as their own jobs — not as default cofactors here.

## Markers people track

Rule-outs first. These are the boring tests that impersonate “I need a peptide”:

- B12
- TSH and Free T3
- Fasting glucose and fasting insulin
- Vitamin D
- Sleep-apnea screen when it should have been done already

Cognitive testing belongs with a clinician if the word is decline, not fog.

## Oral supports that actually map

- Omega-3 DHA — membrane material
- Magnesium (glycinate or threonate) — sleep and NMDA-neighborhood support
- Alpha-GPC — cholinergic supply if that gap is real; not a default stack-on
- Ubiquinol / CoQ10 — electron-transport companion
- Methylated B-complex — if deficiency is the actual finding
- Zinc — if it is actually low

## Evidence tier

**MOTS-c / SS-31 / NAD+** — Tier 2 energy-pathway logic, not a fog trial.  
**Semax** — neurotrophic mechanism with a clinical history outside the U.S.; not a dementia outcome study on this page.  
**Selank** — support, anxiety-adjacent only.

No combined human trial of this pairing. None of this is an Alzheimer’s protocol.

## What this does not cover

Rapid cognitive decline, stroke, new focal signs, or dropping a prescribed dementia or psychiatric medicine because this list exists. Also not a license to skip sleep, alcohol, and apnea because Semax is in the catalog.

## Related compounds

MOTS-c, SS-31, NAD+, Semax. Selank only in the anxiety-adjacent story. Doses, routes (including intranasal), and cycling live on those cards.
