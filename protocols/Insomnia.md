# Insomnia

## The system

The failure here is sleep architecture — not “need a knockout pill.” Clock, night cortisol, caffeine, pain, learned arousal, and apnea all impersonate insomnia. Delta / slow-wave sleep is the stage that carries the largest natural GH pulse, glymphatic clearance, and overnight repair. When that stage is thin, the day gets expensive and the next night is worse.

This page is not a hypnotic. Light, alcohol, and apnea beat this list.

## Category one — the only sleep-specific peptide (primary)

**DSIP** already has a card. The job is delta-sleep architecture and a quieter night-side ACTH/cortisol conversation — not benzodiazepine-style sedation. If the system failure is “I cannot get into or stay in deep sleep,” this is the name that actually maps to that job. Course-based / PRN on its own card. Not every night forever.

## Category two — daytime energy so night can land (support)

A wrecked day is a common reason the night never starts. That is a different failure than a broken sleep switch.

**MOTS-c** — daytime fuel-flexibility / mitochondrial programming. Morning-side in spirit, not a night shot.

**NAD+** — redox carrier. Source notes put it in the morning. Support, not a sleep peptide. If NAD+ makes someone wired at night, it does not belong at bedtime.

## Category three — gut–brain backdrop (support, thin)

**BPC-157** is background inflammatory / barrier conversation when insomnia sits on a loud gut or systemic inflammatory picture. It is not a sleep drug. Leave it off if the only complaint is clock and caffeine.

## How this is not the cortisol page

Chronic stress can wreck sleep. That does not make this page a second HPA protocol. If the primary failure is 24-hour cortisol drive, use the stress map. DSIP crosses over only when broken slow-wave sleep is part of that story — it is centered here.

## Markers people track

- Morning cortisol if HPA is actually the question
- Ferritin / iron if restless legs is in the differential
- Apnea testing when it should have been done already

A wearable “sleep score” is not a diagnosis.

## Oral supports that actually map

- Magnesium glycinate
- Glycine
- Phosphatidylserine (night-side cortisol convention)
- L-theanine
- Melatonin — clock, not architecture; start low if it is used at all

The long source list (milk thistle, NAC, zinc carnosine) is liver/gut spillover. It does not earn a default slot on an insomnia page.

## Evidence tier

**DSIP** — the only compound here whose stated job is sleep architecture. Human data are older and mixed; this is not a modern hypnotic trial.  
**MOTS-c / NAD+** — daytime support jobs.  
**BPC-157** — thin on this page.

No combined human insomnia trial. Lifestyle still does more of this job.

## What this does not cover

Replacing a prescribed hypnotic. Missing apnea. Restless legs from low iron. Pain that is the actual reason sleep never starts.

## Related compounds

DSIP, MOTS-c, NAD+, BPC-157. Doses, timing, and cycling live on those cards.
