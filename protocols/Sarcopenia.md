# Sarcopenia & Frailty Support

## The system

The failure is muscle that is not being kept — motor units, protein, anabolic signal, and mitochondrial output in aging tissue. Training and protein do this job. Peptides here are adjunct conversation around GH-axis lipolysis / lean-mass language and muscle fuel.

This page is not a Tesamorelin recomposition copy and not a TRT page.

## Category one — the stimulus (the honest center)

Progressive load and enough protein. If those are missing, this list is decoration.

## Category two — GH-axis lean-mass conversation (support)

**Tesamorelin** — GHRH / visceral-fat / IGF-1 language. Off-label for general frailty the same way it is off-label for general recomp. Sleep apnea and malignancy questions still apply. Already centered on the recomposition page; import only when that job is the one you mean.

## Category three — muscle fuel / mitochondrial program (support)

**MOTS-c** — AMPK / muscle metabolic program. Coherent in aging muscle.  
**SS-31** — membrane in high-ATP tissue. Muscle qualifies.

**5-Amino-1MQ** — NNMT / NAD-in-fat conversation. More of a body-comp tool than a frailty tool. Leave it on the Tesamorelin page unless fat-mass NAD drain is actually the problem.

## Markers people track

- Grip, gait, sit-to-stand — function, not a scale
- Fasting insulin
- IGF-1 only if a clinician is running a GH-axis agent
- Vitamin D, B12

## Oral supports that actually map

- Protein that actually gets eaten
- Creatine
- Vitamin D3
- Magnesium
- Omega-3

## What this does not cover

Acute fall workup, untreated apnea, or stacking secretagogues because sarcopenia is scary.
