# Card process — after DAC + no-DAC (2026-08-28)

Two cards in one day taught the same lesson twice: the slowness is order, leftover workshop text, and sanding words Kevin has not heard.

Science without a spoken face is a novel. A spoken face without a science brief is a guess. Do both. Do them short.

---

## Order. Do not skip.

### 0. Five answers (2 minutes)

One line each.

1. Famous word in one sentence a stranger thinks they know.
2. What *this* vial does to it (not the sister vial).
3. Who, as a week they already live.
4. What the internet already says — not WTNTY.
5. The catch they have not heard. Must not repeat the face.

### 1. Science brief (one sitting, not a card)

Markers that apply to **every** card:

- What it is, in job language, not a family lecture.
- Human data on *this* compound: found / not found. Do not borrow another molecule’s graphs.
- Dose: practice vs trial. If no trial number, tile will say Start low.
- Timing / food: measured vs convention.
- Cycle / pause: measured vs habit.
- Stop list in body words.
- Pairs: coherent job vs published pair.
- Handling only if it breaks the homepage default.
- Every named paper gets **PMID + DOI on the first write.** Bare last names fail the house even when the paper is real.

Tag each claim: HOLDS UP / OPEN / CONVENTION. Those tags stay in the brief. They never ship in Tier 1.

**CJC-only tax — do not run this on Ipamorelin or later cards:**  
this bottle vs the weekly sister, human data on *this exact name*, cousin clock labeled cousin. That pair is done. Nothing else in the library is that close. Do not invent a twin so the brief has a comparison table.

### 2. Spoken face (the whole fight)

10–14 short sentences. Heard, not read.

Must include: famous-word sentence, name the gland if people have heard the word (pituitary), this vial is / is not, who, start-low or locked live number, when, pause, how you’ll know, stop list, catch that is **not** a repeat of paragraph two.

Banned: insulin, trough, floor, analog, pulsatility, knock, mute, knobs, bigger week, weekday nicknames, IGF-1 as a win, personal protocol, out-of-project cousin names.

Kevin marks the one sentence he would not say. Fix that sentence.

### 3. Card-question gate (before any long file)

Locked list. Every card answers these. A blank row means the brief is not done.

- What is it?
- What is it for?
- Who is it for?
- Why would they use it?
- When would they use it?
- How is it used?
- Dosing
- Timing
- How long / cycling
- Off period / pause
- How you’ll know
- What to watch for / when to stop
- What happens when you stop
- What to take alongside
- What it pairs with
- Handling, only if it breaks the homepage default
- What they’re not telling you (sideways, or none)

Not required on every later card: sister-bottle comparison, cousin clock, receptor-overload essay.

If a required row is empty, fill the brief. Do not draft chips.

### 4. WTNTY — sideways lines, or none

Not reel hygiene. Not the catch restated. Not a quota.

If nothing is actually sideways, write none. If two are obvious, two. If more than two are real and not already on the face, keep them.

If it is only “papers are thin” or “wrong bottle,” it is already on the face. Cut it.

Bachmeyer-shaped is fine if the biology holds and it is tagged OPEN when untested.

### 5. Chips copy the locked face

Tile short. Tap-open = approved paragraph.

Dose tile prints a number only if that number is already the live locked dose. Otherwise: Start low.

Catch tile = the catch sentence. Not the face clock again.

### 6. Research file from the face, not the other way

Tier 1 = spoken face expanded only where a question still has no answer.  
Tier 2 = papers with PMID/DOI.

**Do not put in the file that gets copied to `research/`:**

- FACE LOCKED / HANDOFF-READY / Open before chips / Live library
- HOLDS UP / PLAUSIBLE
- “no entry yet”
- the word that leaked into live copy last time
- household stack details

House rules stay: no treat / cure / reverse / vendor.

### 7. Paste

One PASTE. JSON + chips + research path. Compare only if Kevin says so.  
Say “do not push until Kevin says so.” Do not put ship notes in the research file.  
Do not upload stub `app.js`. Cache bump from whatever is live.
